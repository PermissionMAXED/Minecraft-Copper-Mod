# Asset Credits

All art and audio assets in this folder come from [Kenney](https://kenney.nl)
asset packs, released under the
[Creative Commons Zero (CC0 1.0) Universal](https://creativecommons.org/publicdomain/zero/1.0/)
license — free for personal and commercial use, no attribution required
(but appreciated!).

## Packs used

| Pack | URL | Used for |
| --- | --- | --- |
| UI Pack | https://kenney.nl/assets/ui-pack | Button and stat-bar textures (`tex_btn_*`, `tex_bar_*`) |
| Interface Sounds | https://kenney.nl/assets/interface-sounds | UI sound effects (`sfx_click`, `sfx_back`, `sfx_confirm`, `sfx_error`, `sfx_coin`, `sfx_eat`, `sfx_drop`, `sfx_splash`, `sfx_pop`) |
| Emotes Pack | https://kenney.nl/assets/emotes-pack | Pet emote bubbles (`tex_emote_*`) |
| Game Icons | https://kenney.nl/assets/game-icons | HUD/navigation icons (`tex_icon_*`) |
| Particle Pack | https://kenney.nl/assets/particle-pack | Particle textures (`tex_particle_*`) |
| Music Jingles | https://kenney.nl/assets/music-jingles | Jingles and music (`sfx_win`, `sfx_lose`, `music_main`) |

Audio was converted from OGG to AAC (`.m4a`) for iOS playback; some textures
were downscaled to a maximum width of 512 px. See `Gooby/scripts/fetch_kenney_assets.sh`
for the exact source-file mappings.
